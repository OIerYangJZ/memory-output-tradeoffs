\begin{definition}[$r$-round dispersed stream]
\label{def:w1-dispersed-stream}
Fix $\mathbb F_2$-independent Pauli-$Z$ characters $P_1,\ldots,P_m$ on
$n\geq m$ qubits, a modulus $Q\geq3$, the step $\Delta=2\pi/Q$, an
aggregate alphabet $[K]_0=\{0,\ldots,K-1\}$ with $2\leq K\leq Q$, and
$r\geq2$ rounds.  For $x\in[K]_0^m$, shares
$a^{(1)},\ldots,a^{(r)}\in\mathbb Z_Q^m$ are valid if
\begin{equation}
 \sum_{t=1}^r a_j^{(t)}=x_j\pmod Q
 \qquad(j\in[m]).
 \label{eq:w1-share-sum}
\end{equation}
The \emph{flat input} is the round-major record sequence
$\mathsf{Update}(t,j,a_j^{(t)})$, which implements
$W=\prod_{t}\prod_{j}R_{P_j}(\Delta a_j^{(t)})$; the \emph{semantic
input} is the addressed aggregate vector $x$, which specifies
$U_x=\prod_jR_{P_j}(\Delta x_j)$.
\end{definition}

\begin{proposition}[Semantic equivalence and token privacy]
\label{prop:w1-stream-equivalence}
\label{prop:family-aggregates}
Every valid flat stream implements $U_x$ up to global phase.  No single
record determines $x_j$: for every fixed $(t,j,a)$ and every $b\in[K]_0$
there is a valid stream with $a_j^{(t)}=a$ and $x_j=b$.  Under the
canonical sharing distribution, in which the first $r-1$ shares are
independent and uniform and the last is fixed by
\eqref{eq:w1-share-sum}, every individual residue is uniform on
$\mathbb Z_Q$ and independent of $x_j$.
\end{proposition}

\begin{proof}
Write $\sum_ta_j^{(t)}=x_j+Qk_j$ with $k_j\in\mathbb Z$.  The $P_j$
commute and $Q\Delta=2\pi$, so
$\prod_tR_{P_j}(\Delta a_j^{(t)})=(-1)^{k_j}R_{P_j}(\Delta x_j)$, and the
signs multiply to a global phase.  For privacy, choose any one of the other
$r-1$ residues to enforce the desired sum.  A sum that contains an
independent uniform residue is uniform, which gives the distributional
claim.
\end{proof}

A compiler $\mathcal A$ is \emph{charged} as follows.  It may use
random-access RAM, stacks, hash tables, caches, graph or DAG
intermediate representations, and a random tape, and it may choose its
number of passes dynamically.  Its final output is write-once and is a
codeword of a fixed prefix-free code.  At every execution cut $c$ we
serialize a complete restart snapshot in five disjoint, self-delimiting
fields: control (pass and finite-control state, heads, emitted-prefix
lengths, random tape and cursor), store (RAM, stacks, hash tables, caches,
including computed integer data such as partial sums at their literal bit
length), window (live input tokens), parameter (every live formal angle
parameter), and IR (every other live intermediate object, including any
retained copy of consumed input).  The charged budget is the total literal
length
\begin{equation}
\label{eq:info-budget}
 B_{\mathrm{cut}}(c)=B_{\mathrm{control}}+B_{\mathrm{store}}
 +B_{\mathrm{window}}+B_{\mathrm{parameter}}+B_{\mathrm{IR}}.
\end{equation}
Rebuilding a global phase table, ZX graph, or Pauli network is therefore
allowed but paid for.  Records and parameters are serialized by a fixed
self-delimiting codec, so an address on $n$ qubits costs
$\Theta(\log n)$ bits; the lower bounds below hold for every
self-delimiting serialization whose control field records the
emitted-prefix length, and only the additive terms of the upper bounds
depend on the codec.  The codec and the field-by-field implementation are
specified in the Supplemental Material~\cite{supplement}.

\begin{definition}[Forward-pass accounting]
\label{def:w1-pass-accounting}
Split the round-major stream into Alice's prefix $A$ (rounds
$1,\ldots,r-1$) and Bob's suffix $B$ (round $r$).  A forward $p$-pass
compiler scans $AB$ from left to right at most $p=p(m)$ times; each new
pass is re-delivered by the source from the start of the stream, as in
standard multipass streaming.  A run therefore makes at most $p$ forward
crossings $A\to B$ and at most $p-1$ rewind crossings $B\to A$.  For a run
on input $I$, let $A_p(I)$ be the number of output bits committed while
the machine scans $A$, summed over passes, and let
$\Sigma^{\to}_p(I):=\sum_{t\leq p}B_{\mathrm{cut}}(c_{A\to B,t})$ be the
total snapshot length at the forward crossings.  For randomized
compilers, $\overline A_p:=\max_I\mathbb E_\rho A_p(I,\rho)$,
$\overline\Sigma^{\to}_p:=\max_I\mathbb E_\rho\Sigma^{\to}_p(I,\rho)$,
and the crossing cap is
$S:=\max_I\mathbb E_\rho[\max_cB_{\mathrm{cut}}(c;I,\rho)]$ over the
$2p-1$ crossings, so that $\overline\Sigma^{\to}_p\leq pS$.  Unbarred
symbols denote maxima over valid inputs.
\end{definition}

\begin{definition}[Output measures]
\label{def:info-budget-bits}
The self-contained code $E_{\mathrm{self}}$ serializes a target-basis
circuit with all opcodes, addresses, delimiters, and parameters.  Given
the public dictionary $\mathcal F_m=(m,P_1,\ldots,P_m,K,\Delta)$, the
family-relative code $E_{\mathrm{rel}}(\cdot\mid\mathcal F_m)$ may
instead write the aggregate digits packed in base $K$ (aggregate mode),
complete target-basis records (literal mode), or, under a header that
declares a public schedule, residues packed in base $Q$ without addresses
(ordered-share and $p$-block hybrid modes); the modes are specified in
Appendix~\ref{app:proofs}.  We write $B_{\mathrm{rel}}$ and $B_{\mathrm{self}}$
for the code lengths of an output, and $B^{\mathrm{out}}$ and
$\overline B^{\mathrm{out}}$ for their worst-input value and worst-input
expectation.  Description bits, self-contained bits, and gate counts are
bounded separately and never converted into one another.
\end{definition}
